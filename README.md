# 🧵 Stitches by S - Blouse Pattern Generator

Automatic blouse pattern drafting tool based on Haseena Fashion World measurements.

## Features:
- ✅ 6 Blouse Styles (Basic, Boat, Pot, Katori, Temple, Cut Work)
- ✅ Auto-calculations
- ✅ SVG Pattern Generation
- ✅ Download & Print

## How to Use:
1. Enter your measurements
2. Select blouse style
3. Click Generate Pattern
4. Download or Print
